# BatteryTray

Маленькая утилита для Windows 10/11: в трее справа снизу постоянно висят иконки с процентом заряда наушников и других Bluetooth-устройств. На каждое подключённое устройство — своя иконка с числом.

```
  ┌────────────────────────────┐
  │  ^   85  42   🔊  📶  14:05 │   ← 85% наушники, 42% мышь
  └────────────────────────────┘
```

Ничего устанавливать не нужно: это один PowerShell-скрипт, всё нужное уже есть в Windows.

## Запуск

1. Скопируйте папку `battery-tray` куда-нибудь, где она будет лежать постоянно, например в `C:\Tools\battery-tray`.
2. Дважды щёлкните `start.cmd`. Мелькнёт и закроется чёрное окно, в трее появится иконка.
3. Правый клик по иконке → **Запускать вместе с Windows**. Скрипт будет стартовать сам после входа в систему.

### Windows 11 прячет новые иконки под стрелку «^»

Чтобы иконки всегда были видны, перетащите их мышью из-под стрелки на панель задач. Другой способ: **Параметры → Персонализация → Панель задач → Другие значки в области уведомлений** и включите там пункты **Windows PowerShell**.

## Что умеет

- **Число на иконке** — заряд в процентах. Наведите курсор, и появится название устройства.
- **Красное число** означает низкий заряд. Тогда же приходит уведомление, один раз за разряд.
- **Серая «–»** означает, что сейчас нет подключённых устройств с данными о заряде. Иконка остаётся, чтобы через неё было доступно меню.
- **Левый клик** по любой иконке обновляет данные сразу.
- **Правый клик** открывает меню:
  - список всех найденных устройств; снимите галочку, чтобы спрятать ненужное, например геймпад;
  - «Обновить сейчас»;
  - «Обновлять каждые»: 15 с, 30 с (по умолчанию), 1 мин или 5 мин;
  - «Предупреждать о низком заряде»: выключено, 10%, 20% (по умолчанию) или 30%;
  - «Запускать вместе с Windows»;
  - «Выход».
- **После сна** данные обновляются сами.
- **Тема панели задач** учитывается: на тёмной цифры белые, на светлой чёрные.

Настройки хранятся в `%APPDATA%\BatteryTray\settings.json`.

## Какие устройства увидит

Те же, у которых Windows сама показывает заряд в **Параметры → Bluetooth и устройства**. Скрипт читает то же системное свойство (`DEVPKEY_Bluetooth_Battery`). Обычно это:

- Bluetooth-наушники и гарнитуры: AirPods, Sony, JBL, Samsung, Jabra и т. п. Нужна поддержка профиля Hands-Free, она есть почти у всех;
- Bluetooth-мыши, клавиатуры и геймпады, которые сообщают заряд Windows.

Скрипт **не увидит**:

- устройства с собственным радиоприёмником, например Logitech Unifying/Bolt, Razer HyperSpeed или радиогарнитуры с USB-донглом. Их заряд знает только фирменная программа, например G HUB или Synapse;
- наушники, которые передают заряд только в своё приложение, а не Windows.

Проверить, что видит скрипт, можно через `list-devices.cmd`: он выведет таблицу устройств и процентов.

## Если что-то не так

- **Иконка не появилась.** Возможно, она спряталась под «^» (см. выше). Ещё можно запустить скрипт с консолью и посмотреть ошибки:
  ```bash
  powershell -NoProfile -ExecutionPolicy Bypass -File .\BatteryTray.ps1
  ```
- **Устройства нет в списке.** Посмотрите, показывает ли Windows его заряд в «Bluetooth и устройства». Если нет, то и скрипт его не получит.
- **Процент обновляется с задержкой.** Наушники сами решают, когда сообщать заряд. Обычно это происходит при подключении и при каждом изменении на 10%.
- **Отключить автозапуск** можно в меню или удалив ярлык `BatteryTray.lnk` из папки `shell:startup`.

# RikaNV — трансляция с прибора на телевизор

Программа для Windows. Берёт видео с тепловизора или прицела и показывает его на весь экран телевизора или проектора. Если сигнал пропал, на экране остаётся фирменная заставка «Ожидание сигнала с прибора…», а программа сама переподключается. Ошибок и окон Windows посетители не увидят.

## Как получить программу

Готовый `RikaScopeView.exe` собирается автоматически: GitHub → вкладка **Actions** → **Scope viewer for Windows** → последний зелёный запуск → внизу **Artifacts** → `RikaScopeView-windows`. Скачайте архив и распакуйте его. Python ставить не нужно.

При первом запуске Windows может показать «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае». Программа не подписана сертификатом, отсюда и предупреждение.

## Подготовка на выставке

1. Подключите телевизор к ноутбуку по HDMI. Нажмите **Win+P** и выберите **«Расширить»**: на ноутбуке остаётся рабочий стол, на телевизоре будет картинка.
2. Подключите прибор одним из способов ниже.
3. Запустите `RikaScopeView.exe`, выберите источник и экран телевизора. Нажмите **«Начать трансляцию»**.

### Способы подключения прибора

| Способ | Что нужно | Задержка |
|---|---|---|
| **Wi-Fi прибора** | Включите на приборе Wi-Fi (точку доступа) и подключите ноутбук к этой сети. В программе нажмите **«Найти прибор»** | небольшая, зависит от прибора |
| **Видеовыход прибора** | Кабель видеовыхода прибора и USB-карта видеозахвата (AV/CVBS → USB или HDMI → USB) | минимальная |
| **USB** | Прибор, который определяется в Windows как камера | минимальная |
| **Видеофайл** | Записанный ролик. Запасной вариант, если прибор подвёл: крутится по кругу | — |

«Найти прибор» сам проверяет сеть Wi-Fi и подбирает адрес видеопотока (RTSP). Если найти не удалось, программа объяснит почему. Точный адрес можно взять из инструкции прибора и вписать вручную, например `rtsp://192.168.11.123:554/live`. Если картинка подтормаживает или рассыпается, переключите «Передача» на другой вариант.

Пока ноутбук подключён к Wi-Fi прибора, интернета на нём обычно нет. Это нормально.

VPN на компьютере на время трансляции лучше выключить: он может перехватывать соединения с прибором. Если адрес найти не удалось, нажмите **«Отчёт»** → «Скопировать отчёт» и пришлите текст разработчику: в нём видно, какие устройства есть в сети прибора и что они отвечают.

## Управление во время трансляции

| Клавиша | Действие |
|---|---|
| Esc | остановить и вернуться к настройкам |
| F или F11 | полный экран / окно |
| R | повернуть на 90° |
| M | отразить зеркально |
| + / − | цифровое увеличение, 0 — сброс |
| L | логотип RikaNV вкл/выкл |
| H | подсказка и состояние: источник, размер кадра, кадров в секунду |

Клавиши работают и в русской раскладке.

Галочка **«Сразу начинать трансляцию при запуске программы»** нужна для выставки. Положите ярлык программы в автозагрузку (Win+R → `shell:startup`), и после включения ноутбука трансляция начнётся сама.

## Для разработчика

Запуск из исходников: Python 3.10+, затем `run.bat` или `pip install -r requirements.txt` и `python scope_viewer.py`.

Ключи командной строки:
- `--source` — адрес потока, номер устройства или путь к видеофайлу;
- `--monitor N` — номер экрана, начиная с 1;
- `--windowed` — показать в окне;
- `--auto` — сразу начать трансляцию с сохранёнными настройками.

Настройки хранятся в `%APPDATA%\RikaScopeView\config.json`.

- `scope_viewer.py` — окно настроек и запуск.
- `viewer.py` — захват в отдельном потоке (хранится только последний кадр, задержка не копится), вывод на экран, заставка.
- `discovery.py` — поиск RTSP-потока в сети прибора.

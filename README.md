# RikaNV — промостраница

Размер скидки — **10%**, срок действия промокода — **1 год (365 дней)** с получения. Обратного отсчёта нет.

Короткая праздничная страница для GitHub Pages: Дмитрий Шаханов протягивает карточку со скидкой, портрет мягко двигается. Нажатие открывает rikasale.ru в новой вкладке, страница со скидкой остаётся открытой. Есть конфетти и кнопка остановки анимации; учитывается настройка уменьшения движения. Чистые HTML, CSS и JavaScript, сборка не нужна.

На первом экране телефона, до портрета, находятся крупные −10%, карточки подарка и розыгрыша и кнопка получения. Подарок — за форму, шанс на суперприз — при покупке на стенде. Эти условия и кнопка помещаются без прокрутки на экране 320 × 568.

Портрет в `assets/dmitry-fresh-v4.webp` создан заново по исходным фотографиям: крупный план, без очков, с нашивкой RikaNV. Дмитрий протягивает карточку одной рукой к посетителю. Изображение 1254 × 1254 сохранено в WebP без потерь и отображается шириной не более 560 CSS-пикселей. Движение выполняется на целое число пикселей, без масштабирования и 3D-наклона; конфетти находится позади портрета. На карточке указаны только 10%; сам промокод появляется в форме после успешного ответа сервера. Стили композиции — в `founder.css`. Условия скидки выделены отдельной светлой плашкой.

## Текущее состояние

Форма подключена к `https://test.rika-nv.ru/api/promo/leads`. Обработчик запущен на сервере и отправляет заявки в привязанный Telegram. Доставка подтверждена 19.10.2026. 20.10.2026 срок увеличен до 365 дней; ранее выданные коды продлены от первоначальной даты выдачи с сохранением всех заявок и погашений. Повтор существующей тестовой заявки подтвердил новый срок через API без нового лида. Публичный адрес страницы: https://nvrika404-beep.github.io/promo/. GitHub Pages публикует файлы из корня ветки main.

Серверная часть поставляется отдельно в архиве `rikanv-lead-service.zip`. В публичный репозиторий её загружать не нужно. Токен Telegram никогда не добавляйте в HTML, JavaScript или GitHub.

## Механика

- Имя, телефон и email обязательны.
- После сохранения заявки сервер возвращает промокод **Shahanov10**. Он общий для акции, но срок и применение учитываются отдельно по каждому телефону.
- Срок — 365 × 24 часа с момента первой выдачи, время окончания показано по Москве спокойной строкой под кодом.
- Один нормализованный номер телефона может зарегистрировать скидку только один раз. Повторная выдача, включая выдачу после истечения срока, запрещена сервером и уникальным индексом базы.
- Повтор одной и той же отправки после сетевой ошибки возвращает первоначальный код, не продлевая срок.
- Таймер и акцент на срочности удалены. По окончании года показывается сообщение об истечении срока, копирование выключается. Сервер отдельно проверяет срок при погашении.
- Браузер сохраняет код, точный срок и версию формата (2), без имени, телефона или email. Старые записи без версии с кодом Shahanov10 получают однократную поправку +358 дней к прежней дате, совпадающую с миграцией сервера; текущая дата для продления не используется. Перезагрузка больше не меняет срок. Для другого посетителя есть кнопка возврата к форме; запрет повторной выдачи тому же телефону проверяет сервер.
- Подарок получают на стенде после заполнения формы, пока подарки есть в наличии. Конкретные виды подарков не перечислены. Менеджерам не требуется отмечать подарки в боте.
- Возможность участия в розыгрыше суперприза связана с покупкой на стенде; заявка сама по себе не регистрирует участие.

## Как разместить на GitHub Pages

1. Распакуйте архив сайта.
2. Загрузите `index.html`, `celebration.css`, `founder.css`, `app.js`, `celebrate.js`, `config.js`, папку `assets` и файл `.nojekyll` в корень репозитория `promo`.
3. В Settings → Pages выберите публикацию из корня нужной ветки. Все пути относительные: адрес `/promo/` поддерживается.
4. Адрес обработчика уже указан в `config.js`; токен или другие секреты сюда добавлять не нужно.
5. Отправьте согласованную тестовую заявку и проверьте, что она пришла в ваш Telegram, а код и срок появились на странице.

## Важно для применения скидки

Новые коды создаются отдельным сервисом. Они не появляются автоматически в системе скидок rikasale.ru. Сейчас предусмотрена проверка и погашение сотрудником через Telegram-бота по телефону из заявки. Само знание общего кода не подтверждает регистрацию или право на скидку. Для автоматического применения в корзине нужно отдельно связать обработчик с системой магазина.

Обязательные поля и запрет повторов номера реализованы; проверка владения номером через SMS в этот вариант не включена.

## Проверено

Верстка на 320, 390 и 1440 px; обязательные поля; отсутствие ложного успеха без сервера; обработка ошибки и повторной отправки; раскрытие кода только из успешного ответа сервера. Реальная доставка в Telegram подтверждена отдельной тестовой заявкой. Независимая проверка выявила два сбоя восстановления после ошибок Telegram/БД; они исправлены и покрыты тестами.

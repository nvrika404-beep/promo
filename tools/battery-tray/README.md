# BatteryTray

Маленькая программа для Windows 10/11: в трее справа снизу постоянно висят иконки с процентом заряда наушников и других Bluetooth-устройств. На каждое подключённое устройство — своя иконка с числом.

```
  ┌────────────────────────────┐
  │  ^   85  42   🔊  📶  14:05 │   ← 85% наушники, 42% мышь
  └────────────────────────────┘
```

Это один файл `BatteryTray.exe` размером несколько десятков килобайт. Установка не нужна: всё, что ему требуется (.NET Framework 4), уже есть в Windows 10 и 11.

## Где взять exe

**Готовый.** Его собирает GitHub Actions: вкладка **Actions** → последний запуск **BatteryTray** → внизу, в разделе **Artifacts**, архив **BatteryTray**. Внутри лежит `BatteryTray.exe`.

**Собрать самому.** Дважды щёлкните `build.cmd`, рядом появится `BatteryTray.exe`. Используется компилятор C#, который уже есть в Windows, так что ничего ставить не нужно.

## Запуск

1. Положите `BatteryTray.exe` туда, где он будет лежать постоянно, например в `C:\Tools\`.
2. Запустите его двойным щелчком. При первом запуске Windows SmartScreen может предупредить о неизвестном издателе: нажмите «Подробнее» → «Выполнить в любом случае».
3. Правый клик по иконке → **Запускать вместе с Windows**.

### Windows 11 прячет новые иконки под стрелку «^»

Перетащите иконки мышью из-под стрелки на панель задач. Windows это запомнит. Другой способ: **Параметры → Персонализация → Панель задач → Другие значки в области уведомлений** → включить **BatteryTray**.

## Что умеет

- **Число на иконке** — заряд в процентах. Наведите курсор, и появится название устройства.
- **Красное число** означает низкий заряд. Тогда же приходит уведомление, один раз за разряд.
- **Серая «–»** означает, что сейчас нет подключённых устройств с данными о заряде. Иконка остаётся, чтобы через неё было доступно меню.
- **Левый клик** по любой иконке обновляет данные сразу.
- **Правый клик** открывает меню:
  - список всех найденных устройств; снимите галочку, чтобы спрятать ненужное, например геймпад;
  - «Обновить сейчас»;
  - «Обновлять каждые»: 15 с, 30 с (по умолчанию), 1 мин или 5 мин;
  - «Предупреждать о низком заряде»: выключено, 10%, 20% (по умолчанию) или 30%;
  - «Запускать вместе с Windows»;
  - «Выход».
- **После сна** данные обновляются сами.
- **Тема панели задач** учитывается: на тёмной цифры белые, на светлой чёрные.

Настройки хранятся в `%APPDATA%\BatteryTray\settings.ini`.

## Какие устройства увидит

Те же, у которых Windows сама показывает заряд в **Параметры → Bluetooth и устройства**. Программа читает то же системное свойство (`DEVPKEY_Bluetooth_Battery`). Обычно это:

- Bluetooth-наушники и гарнитуры: AirPods, Sony, JBL, Samsung, Jabra и т. п.;
- Bluetooth-мыши, клавиатуры и геймпады, которые сообщают заряд Windows.

Программа **не увидит**:

- устройства с собственным радиоприёмником, например Logitech Unifying/Bolt, Razer HyperSpeed или радиогарнитуры с USB-донглом. Их заряд знает только фирменная программа, например G HUB или Synapse;
- наушники, которые передают заряд только в своё приложение, а не Windows.

Все найденные устройства и их заряд, в том числе отключённых, видны в меню по правому клику.

## Если что-то не так

- **Иконка не появилась.** Возможно, она спряталась под «^» (см. выше).
- **Устройства нет в списке.** Посмотрите, показывает ли Windows его заряд в «Bluetooth и устройства». Если нет, то и программа его не получит.
- **Процент обновляется с задержкой.** Наушники сами решают, когда сообщать заряд. Обычно это происходит при подключении и при каждом изменении на 10%.
- **Отключить автозапуск** можно в меню, а удалить программу — просто удалив exe.
